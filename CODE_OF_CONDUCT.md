# Code of conduct

Short version: be useful, be kind, assume the other person is trying.

## Expected

- Critique the change, not the person.
- Say what evidence would change your mind.
- Accept that maintainers can say no to scope, even to good work.

## Not expected

- Harassment, dogpiling, or gatekeeping over tooling choices.
- Pasting live API keys or embargoed victim data into issues.
- Drive-by rewrites with no test and no rationale.

## Enforcement

Report problems through a GitHub issue or the security advisory link. A maintainer will confirm,
explain the call and, for repeat behaviour, limit participation. There is no committee and no
appeal process beyond asking again with new detail.
